# Fiscalización de diputaciones federales 2024

Reporte facsimilar de nueve páginas sobre fiscalización electoral del Proceso
Federal 2023–2024.

## Contenido

- `index.html`: versión web visualmente equivalente al documento de referencia.
- `reporte_desde_html.pdf`: PDF generado desde el HTML.
- `que_se_sanciono_diputaciones_federales_2024.pdf`: PDF original de referencia.
- `assets/`: imágenes de las nueve páginas.

El sitio incluye un botón para descargar el PDF generado desde HTML.

## Consulta

Al habilitar GitHub Pages, el reporte puede consultarse directamente desde la URL
pública del proyecto.
