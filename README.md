# Observaciones de fiscalización del PEF 2023–2024

Reporte analítico sobre la fiscalización federal de precampaña y campaña para
Presidencia, senadurías y diputaciones. Responde, con fuentes primarias del INE
y del TEPJF:

1. qué partido acumuló más conclusiones sancionatorias directas;
2. cuál de esos casos trascendió a expedientes jurisdiccionales;
3. qué cadena terminó en una sanción confirmada.

## Resultados centrales

- **A:** Morena, con 194 conclusiones directas.
- **B:** Morena, en `SUP-RAP-88/2024` y `SUP-RAP-413/2024`.
- **C:** Morena, Conclusión `7_C75_FD`; sanción de **$306,167.40** confirmada
  en `SUP-RAP-104/2025`.

Las conclusiones registradas a coaliciones se mantienen en una categoría
separada para no duplicarlas entre sus partidos integrantes.
